# Reel Framework V2 — план

Документ описывает, как перестроить пайплайн GhostPepe-роликов так, чтобы:

1. контент **никогда** не заезжал в красные зоны Instagram Reels;
2. защита от заезда была **реальной** (падение рендера/QA), а не мёртвым кодом;
3. был **один источник правды** по геометрии и токенам;
4. ролики перестали выглядеть как слайд-шоу из uppercase-надписей.

Кода пока не пишем — это спецификация под реализацию. Выбранные параметры: safe-zone «сбалансированно», QA со скриншот-гейтом.

## 2. Единый источник правды: `safe-area.ts`

Новый модуль `src/reel-system/layout/safe-area.ts` — **единственное** место, где живут числа. Всё остальное (`theme/layout.ts` per-reel зоны, инлайн в guard) удаляется или ре-экспортируется отсюда.

Параметры «Сбалансированно» для 1080×1920:

```ts
export const CANVAS = { width: 1080, height: 1920 } as const;

// Красные зоны Instagram Reels (unsafe — сюда нельзя непрозрачный контент)
export const IG_UNSAFE = {
  top:    { x: 0,   y: 0,    width: 1080, height: 220 },   // «Reels», камера
  bottom: { x: 0,   y: 1440, width: 1080, height: 480 },   // ник, подпись, аудио, прогресс
  right:  { x: 900, y: 980,  width: 180,  height: 620 },    // лайк/коммент/шер/ещё/диск
} as const;

// Позитивная безопасная область для верстки (где ЖИТЬ контенту)
export const SAFE = {
  left: 90, right: 90, top: 240, bottom: 500,
  // производные
  x: 90, y: 240, width: 900, height: 1180,       // общий безопасный прямоугольник
  captionBottom: 520,                             // низ субтитров не ниже этого отступа снизу
  captionMinGapToBottomZone: 40,
} as const;
```

Правила:
- **Текст/иконки/CTA/hero-критические области** держатся внутри `SAFE` прямоугольника и не пересекают `IG_UNSAFE.right`.
- **Фон и полноэкранный декор** могут уходить под зоны (это ок) — они не критические.
- Субтитры: центр по X, низ не ниже `bottom:520`, максимум 2 строки.
- Бренд-строка `@ghostpepebot` переезжает **внутрь** безопасной зоны (например верх-лево под топ-зоной, y≈250, либо низ но выше `y=1400`), а не в `bottom:178`.

Хелперы модуля:
```ts
boxIntersectsUnsafe(box): { hit: boolean; zones: string[] }
clampIntoSafe(box): BoundingBox           // прижать к безопасной области
captionSlot(lines): BoundingBox           // готовый слот субтитров
assertSafe(box, id): void                 // бросает в dev/QA если box в красном
```

## 3. Layout-примитивы (чтобы верстать нельзя было «мимо»)

Вместо ручных `position:absolute; top:1368` — компоненты, которые **физически не дают** выйти за зону:

- `<SafeArea>` — `AbsoluteFill` с внутренними отступами `SAFE`; всё внутри позиционируется относительно неё, а не 1080×1920.
- `<CaptionSafeArea>` — фиксированный слот субтитров (центр, `bottom:520`, авто-перенос ≤2 строк, авто-fit размера шрифта под ширину `SAFE`).
- `<CriticalBox id kind>` — замена `CriticalElement`, но: (а) регистрирует box через `useLayoutEffect` (не в теле рендера — чинит D4); (б) в dev/Studio рисует свой bbox; (в) вызывает `assertSafe` под флагом.
- `<SafeZoneOverlay show>` — рисует ВСЕ три `IG_UNSAFE` зоны + границу `SAFE` из единого источника (чинит D3). Включается query-параметром/env в Studio и в контрольных кадрах.

Итог: верстальщик работает в координатах безопасной области; «красная зона» становится недостижимой по построению, а не по договорённости.

## 4. Реальное принуждение (чиним D2/D5)

Три уровня защиты, все читают `safe-area.ts`:

1. **Render-time assert (dev/QA).** `LayoutRegistryProvider` в конце кадра (через `useLayoutEffect` + Remotion `delayRender`/`continueRender` на нулевом кадре, либо простой проход по `elements.current`) прогоняет `validateSafeZones`+`validateCollisions`. При флаге `REEL_QA=1` — бросает ошибку, рендер падает. В обычном предпросмотре — рисует красный баннер поверх (оживляем `CollisionGuard`).
2. **Registry-checker (быстрый, код-уровень).** Скрипт `scripts/check-safe-zones.mjs` импортирует зарегистрированные box'ы (через тест-рендер каждого composition в jsdom или через экспортируемые layout-манифесты) и валидирует. Встраивается в `qa:gate`.
3. **Скриншот-гейт (пиксельный, ловит D5).** См. раздел 5.

`quality-gate.ts`: поле `safeZoneValid` наконец начинает вычисляться реально из (2)+(3), а не проставляться руками.

## 5. Скриншот-гейт (`npm run qa:reels`)

Ловит то, что не зарегистрировано как критический элемент (бренд-строки, декор, «уехавший» текст).

Алгоритм на каждый composition:
1. `remotion still` рендерит 3 контрольных кадра (старт / середина / CTA) в `out/qa/<reel>-{01,02,03}.png`. Есть основа: `render:checks` / [render-checks.mjs](../scripts/render-checks.mjs).
2. Для каждой `IG_UNSAFE` зоны считаем «энергию контента» внутри маски: доля пикселей, чья яркость/альфа заметно отличается от фона (порог настраиваемый). Фон под зоной — ок; яркий текст/иконка/карточка — нарушение.
3. Порог: если непрозрачного/яркого контента в зоне > N% (напр. 2%) → **FAIL** с сохранением диффа `out/qa/<reel>-<zone>-VIOLATION.png` (кадр + подсвеченная зона + пятно нарушения).
4. Дополнительно рендерим кадры **с оверлеем** `SafeZoneOverlay` для глазами-ревью и вставки в PR.

Реализация: Node + рендер кадров Remotion + попиксельный проход (можно `@remotion/renderer` в headless или уже используемый Playwright MCP для скриншотов Studio). Без тяжёлых CV-библиотек — простая яркостная эвристика по маске зон.

Интеграция: `build:reel` и CI-хук вызывают `qa:reels`; ненулевой exit блокирует рендер финала.

## 6. Визуальный апгрейд (чиним D6) — отдельная фаза

Не входит в текущий объём (выбрана «только диагностика+план»), но фиксирую направление, чтобы safe-area строилась с запасом под это:

- **Design tokens.** Расширить `theme/`: `spacing` (шкала 8/16/24/40/64), `elevation` (тени-пресеты), `motion` (уже есть `CALM_SPRING` — добить библиотекой enter/exit/emphasis пружин и bezier). Один `tokens.ts`.
- **Композиция вместо слайдов.** Не менять полноэкранные надписи встык, а держать **постоянную сцену-«камеру»** (как в TwoNetworks `cameraScale/cameraY`) и внутри неё двигать фокус. Текст — акцент, не весь кадр.
- **Типографика.** Отойти от тотального uppercase Unbounded 800. Ввести иерархию: kicker (Manrope 700 caps small) → headline (Unbounded) → subhead. Меньше слов, крупнее ключевое.
- **Глубина.** Слои с parallax, blur-фон, стекло/`backdrop`-карточки из единых `elevation`-пресетов, свечение из `colors.mint` — уже есть, но разрозненно.
- **Субтитры.** Один компонент `CaptionSafeArea` с word-highlight (мятный `#22F0D0`), плавным появлением, стабильной шириной.
- **Референсы.** Собрать борд «хороших» Remotion-рилсов, разложить на приёмы (тайминг хука 0–1.5с, ритм смен, motion-подписи) → внести в `REEL_PIPELINE.md` как чек-лист creative direction.
