# Озвучка: от текста до WAV

Весь TTS-слой параметризован одним файлом — [config/voice.config.mjs](../config/voice.config.mjs).
Магических чисел в коде нет: если что-то нужно поменять, это меняется там.

кастингом 8 августа 2026. Свой голос не создавался, клонирование не

|---|---|

## Цепочка

```
текст сценария
  ↓ числа прописью          детерминированно, без модели
  ↓ Audio Tags              LLM предлагает → валидатор режет
  ↓ чанкинг по сценам       минимум 250 символов на чанк
  ↓ синтез                  N дублей на чанк, кэш по хешу
  ↓ high-pass 80 Гц         в Node, по PCM
  ↓ обрезка тишины          в Node, по RMS
  ↓ склейка с гапом 300 мс
  ↓ нормализация −16 LUFS   ffmpeg loudnorm, два прохода
WAV 48 кГц моно + манифест + сшитый alignment
```

## Числа прописью

[numerals.mjs](../scripts/eleven/lib/numerals.mjs) — потому что модели этого не
умеют. На одной и той же задаче бесплатные и платные модели выдали «МАЙ ДВАДЦАТЬ
ЧЕТЫРЕХТЫСЯЧ», «Май двести двадцать четвёртый» и «на семнадцатом пять» там, где
нужно «май две тысячи двадцать четвёртого» и «семнадцать и пять».

Написание числа — арифметика, поэтому оно живёт в коде:

| Вход | Выход |
|---|---|
| `В мае 2024 запустили стандарт` | в мае **две тысячи двадцать четвёртого** |
| `Трекеры до 2000 года` | до **двухтысячного** года |
| `Айфоны на 17.5` | на **семнадцать и пять** |
| `Chrome 119 шлёт 3 заголовка` | **сто девятнадцать** шлёт **три** |
| `Доля выросла на 42%` | на **сорок два процента** |

Год определяется по контексту: 1900–2099 рядом с месяцем, словом «год» или
предлогом даты берёт родительный падеж, всё остальное — обычное количественное.
На экране остаётся исходное написание через `displayReplacements`.

**Чего модуль не делает:** падежное согласование с предлогом. «Из 3000000»
станет «из три миллиона», а не «из трёх миллионов». Числа лучше ставить в
позицию, где работает именительный.

## Audio Tags

[tags.mjs](../scripts/eleven/lib/tags.mjs). Разметку предлагает LLM, но
валидатор имеет право только удалять — добавить он ничего не может.

Разрешены: `[calm]` `[confident]` `[matter-of-fact]` `[curious]` `[thoughtful]`
`[emphatic]` `[pause]` `[whispers]`.

Режется:

- всё вне whitelist — `[excited]`, `[laughs]`, `[gasps]` и прочая переигровка;
- SSML целиком: `<break>` в v3 не поддерживается;
- плотность выше одного тега на два предложения;
- `[whispers]` второй раз или вне хука.

Акценты делаются пунктуацией: многоточие — пауза, КАПС — ударение, запятая —
дыхание. Теги в кадр не попадают: сборщик субтитров выбрасывает токены вида
`[…]`.

## Чанкинг

Чанк — это сцена, а не предложение: в коротком запросе теги ведут себя
непредсказуемо. Глава короче 250 символов приклеивается к соседней, а звук
режется уже после генерации.

Чанк перестаёт расти, как только добрал минимум — иначе весь сценарий склеивался
бы в один запрос. Пример на реальном ролике:

```
#0  267 симв  hook+what+notcookie
#1  370 симв  more+print+defense+cta
```

**`previous_text` / `next_text` с `eleven_v3` недоступны.** API отвечает
`unsupported_model`. Это конфликт внутри требований: v3 выбран ради тегов, а
контекст соседей с ним не сочетается. Контекст отправляется только моделям из
`GENERATION.supportsNeighbourContext`; для v3 непрерывность держится на том, что
чанк — целая сцена, а граница сцены и так естественная точка сброса интонации.

## Дубли и кэш

`takesPerChunk` дублей на чанк, все сохраняются в
`public/generated/<slug>/takes/`, длительность каждого — в манифесте. Выбор
дубля пока первый по порядку; остальные лежат рядом для сравнения.

Кэш: `sha256(размеченный текст чанка + voice_id + модель + формат + настройки)`.
Совпал — запрос не уходит.

Стоимость линейна по дублям: ролик на 640 символов при трёх дублях стоит 1 920.
`--takes 1` для черновика, три — для финала.

## Постобработка

`highpass` и `silenceremove` в билде ffmpeg от Remotion **отсутствуют** — есть
только `loudnorm`, `atrim`, `adelay`, `concat`, `volume`. Поэтому:

- **high-pass 80 Гц** — биквад Баттерворта второго порядка по PCM в
  [wav.mjs](../scripts/eleven/lib/wav.mjs). Ниже 85 Гц не бывает мужской
  основной тон, так что фильтр стоит под сигналом;
- **обрезка тишины** — RMS-гейт по окну 10 мс с порогом −45 dB;
- **нормализация** — ffmpeg `loudnorm`, два прохода: сначала замер, потом
  коррекция с измеренными значениями. Один проход — динамический эффект, он
  качает на речи.

Нормализация идёт **последней, по всему треку**. Нормализовать чанки по
отдельности значило бы сделать все сцены одинаково громкими и убить динамику.

Замер на реальном ролике: вход −20.54 LUFS → выход −16 LUFS, пик −1.5 dBFS.

## Сшивка alignment — самое хрупкое место

Alignment каждого чанка отсчитывается от его собственного аудио **до** обрезки.
Значит, для попадания на общий таймлайн нужно вычесть срезанную с начала тишину
и прибавить позицию чанка:

```js
startMs: entry.startMs - trimmedLeadingMs + chunkStartMs
```

Ошибка здесь рассинхронизирует все субтитры ролика, поэтому выражение одно и в
одном месте. `trimmedLeadingMs` специально протаскивается из шага обрезки в
манифест.

## Команды

```bash
npm run reel:<name>:voice                  # весь TTS-слой
node scripts/eleven/generate-voice.mjs --slug <name> --takes 1   # черновик
node scripts/eleven/generate-voice.mjs --slug <name> --force     # игнорировать кэш
npm run voice:cast:premade                 # кастинг по доступным голосам
npm run voice:cast                         # кастинг по Voice Library (нужен платный тариф)
```

## Защита от случайной переозвучки

Смена голоса, модели или формата в `.env` обесценивает весь кэш сразу. Если
текст ролика не менялся, а параметры другие — генерация останавливается и
показывает, что именно поменялось и сколько символов спишется. Продолжить можно
только с `--force`.

Это появилось после того, как проверочный прогон после смены модели молча
переозвучил два готовых ролика и съел 1 790 символов месячной квоты.
