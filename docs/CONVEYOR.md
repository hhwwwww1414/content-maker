# Конвейер: от идеи до готового ролика

Конвейер производит батч роликов за один заход. Творческую часть — идею и
сценарий — заполняет агент; всё остальное механизировано и закрыто гейтами.

## Как это делится

| Стадия | Кто | Чем закрыта |
|---|---|---|
| Бюджет и размер батча | `conveyor:plan` | живая квота ElevenLabs |
| Идея и фактура | агент | бриф + список 52 снятых тем |
| Сценарий | агент | `docs/REEL_CRAFT.md` |
| Сцены | агент, из готовых грамматик | `docs/GRAMMARS.md` |
| Проверка до трат | `conveyor:preflight` | 12 гейтов по тексту |
| Озвучка, рендер, QA | `conveyor:build` | `scripts/eleven/all.mjs` |

Кода под конкретный ролик не пишется вообще: сцены собираются из восьми
грамматик, композиция генерируется скаффолдером.

## Три команды

```bash
npm run conveyor:plan -- --count 6          # бюджет и бриф
#   … агент заполняет слоты и пишет content/<slug>-reel.json
npm run conveyor:preflight -- --batch <id>  # все гейты, кредиты не тронуты
npm run conveyor:build -- --batch <id>      # озвучка → рендер → лист → QA
```

Артефакты батча — в `runs/conveyor/<id>/`: `batch.json`, `brief.md`,
`preflight.json`, `build.json`. Папка в `.gitignore`.

## Почему препролёт — главный шаг

ElevenLabs берёт деньги за символы, а не за удачные дубли. Ролик, который
оказался 67-секундным или открылся шаблоном, стоит ровно столько же, сколько
удачный, — но квоту он уже съел.

Препролёт судит сценарий до вызова API:

**По каждому ролику**
- бюджет символов и **прогноз длительности** — формула откалибрована по
  реальным замерам, ошибка ≈ 0.4 с; при перерасходе сразу говорит, сколько
  символов резать;
- ссылки на реплики: любой `at` / `until` / `from` / `to` / `*At`, указывающий
  на несуществующий id, — провал, а не молча погасший элемент;
- грамматики: тип известен, главы не используют одну и ту же на весь ролик;
- слоп-гейт: вода, машинные обороты, смягчители, форма хука, число
  проверяемых фактов, повтор первой реплики с другими сценариями;
- фактическая рамка: `banPatterns` и `requiredTexts`;
- обязательная структура: CTA, кадр-запоминалка, `publish.sources`.

**По батчу**
- общие 5-граммы между сценариями;
- одинаковые заходы;
- однообразие: если последовательности грамматик почти совпадают, батч
  завернут — библиотека шаблонов не должна превращать шесть роликов в один.

**Бюджет батча против остатка квоты.** Если на все ролики не хватает, сборка не
начнётся вовсе.

Пример на настоящем ролике:

```
✗ ai-browser-hijack  1114 симв · ~67.2s · 45 реплик · фактов 8 ·
                     грамматики: statement > compare > tiles > document > counters > steps
    ✗ прогноз 67.2s > 60s — убрать примерно 120 символов текста

бюджет: 1114 символов на батч
        квота 46 — НЕ ХВАТАЕТ, нужно ещё 1068

✗ ПРЕПРОЛЁТ ПРОВАЛЕН — кредиты не тронуты
```

Фактическая длительность этого ролика — 66.77 с. Прогноз ошибся на 0.4 с.

## Планирование под квоту

`conveyor:plan` спрашивает у ElevenLabs остаток и режет размер батча под него.
На free-тарифе это 10 000 символов в месяц — примерно **девять роликов**, и
конвейер не даст запланировать больше:

```
батч 2026-08-08
  квота        46/10000 символов (free, сброс 2026-08-31)
  запрошено    6
  ОГРАНИЧЕНО   0 — хватает на 0 из 6
```

Бюджет по умолчанию — 950 символов на ролик, это ≈57 с готового видео с запасом
до потолка в минуту. Переопределяется флагом `--chars`.

Сценарии писать можно и без квоты: они ничего не стоят и лежат готовыми до
сброса лимита.

## Что делает агент

Бриф генерируется под конкретный батч и содержит: остаток квоты, число слотов,
бюджет символов на ролик, ссылки на правила и **список всех уже снятых тем**,
чтобы идея не повторилась.

От агента требуется на каждый слот:

1. тема с проверяемым фактом — имя, дата, число;
2. `content/<slug>-reel.json` по правилам ремесла;
3. сцены — только из восьми грамматик, разные последовательности между роликами;
4. `node scripts/eleven/scaffold-reel.mjs --slug <slug>`.

Скаффолдер идемпотентен: создаёт композицию и контактный лист, регистрирует их
в `src/Root.tsx`, добавляет семь npm-скриптов. Повторный запуск ничего не ломает.

## Сборка

`conveyor:build` прогоняет препролёт, подключает композиции, строит заглушки
таймлайнов и дальше по каждому ролику вызывает существующий
`scripts/eleven/all.mjs`: озвучка (с кэшем по хешу текста) → MP4 → контактный
лист → публикационные тексты → QA по готовому файлу.

Падение одного ролика не останавливает остальные — батч доходит до конца и
показывает сводку:

```
✓ topic-a   54.1s · QA passed
✗ topic-b   61.8s · QA failed
    · durationSeconds: 61.8s вне 30–60s

1/2 роликов готовы к публикации
```

## Модели: кто что делает и сколько стоит

Две роли с противоположными требованиями, обе настраиваются в `.env`:

| Роль | Модель | Замер на живой задаче |
|---|---|---|
| Текст: идеи, хуки, реплики | `nvidia/nemotron-3-ultra-550b-a55b:free` | 4.2 с, чистый русский, держит лимит слов |
| Структура: главы, грамматики, cue | `inclusionai/ling-2.6-flash` | 2.8 с, валидный JSON, **$0.0000076 за вызов** |

Фолбэки — `nemotron-3-super-120b:free` и `gpt-oss-20b:free`. Они нужны не для
красоты: `gemma-4-31b:free` в тесте отдала 429 с первой же попытки, бесплатные
модели ограничены по скорости и периодически недоступны.

Два наблюдения из тестов, оба вшиты в клиент:

- Сильные бесплатные модели **игнорируют `response_format: json_object`** и
  отвечают прозой. Поэтому текст и JSON разведены по разным моделям: пишет
  сильная, форматирует дешёвая.
- Reasoning-модели тратят весь бюджет токенов на размышления в `content`.
  Клиент шлёт `reasoning: {exclude: true}`.

Про «модель, которая использует скиллы»: модель по API не может загрузить
скиллы Claude Code — это возможность харнесса. Эквивалент здесь честный и
явный: `buildSystemPrompt` подставляет в системный промпт сам текст
`docs/REEL_CRAFT.md` и `docs/GRAMMARS.md`. Правила, которым следует модель, —
это ровно те правила, которые потом проверяют гейты, и второй копии, способной
разойтись, не существует.

## Проверка источников — главный анти-слоп

Модель, которую просят «найти трендовую тему», уверенно выдумает исследование,
дату и ссылку. Ни один текстовый гейт этого не поймает: фраза читается
безупречно.

Поэтому каждая идея приходит с источником, и каждый источник запрашивается по
HTTP. Реальный прогон:

```
модель вернула 7 идей, проверяю источники…
  ✓ ai-voice-scam-48k
  ✗ passkey-phishing-proof — fidoalliance.org/specs/… → 404
  ✓ chrome-webfingerprint-2024
  ✓ ai-agent-prompt-injection-email
  ✗ sms-2fa-ss7-redirect — ptsecurity.com/… → unreachable
  ✗ router-upnp-hole — rapid7.com/… → 404
  ✗ browser-extension-data-harvest — developer.chrome.com/… → 404

принято 3 из 7, отклонено 4
```

**Больше половины ссылок оказались выдуманными.** Идея, которую нельзя
проверить, отбрасывается, а не чинится. Отсюда флаг `--overshoot`: просить
надо больше, чем нужно.

## Экономика: сколько стоят 100 роликов

Узкое место — не модели, а озвучка.

| Статья | 100 роликов | Комментарий |
|---|---|---|
| OpenRouter: идеи | $0 | бесплатные модели |
| OpenRouter: структура | **< $0.05** | ~$0.0001 на ролик |
| ElevenLabs | **~95 000 символов** | ~950 симв. на ролик |

$5 на OpenRouter хватит на тысячи роликов. На 100 озвучек — не хватит:

| Вариант | Символов в месяц | Роликов в месяц | 100 роликов |
|---|---|---|---|
| Free × 2 аккаунта (сейчас) | 20 000 | ~21 | ~5 месяцев, $0 |
| Starter, $5/мес | 30 000 | ~31 | ~3.2 месяца, ~$16 |
| Creator, $22/мес | 100 000 | ~105 | 1 месяц, $22 |
| Silero, локально | ∞ | ∞ | $0 |

Silero уже в репозитории и не стоит ничего, но теряет character-alignment, а
вместе с ним кинетические субтитры и точные тайминги грамматик. Это размен
качества на объём, а не бесплатный обед.

**Вывод: «$5 → 100 видео» достижимо по LLM с запасом в сотни раз и недостижимо
по озвучке. Чтобы делать 100 роликов в месяц голосом ElevenLabs, нужен тариф
Creator за $22.**

Несколько бесплатных аккаунтов ради обхода лимита — риск по правилам
ElevenLabs. Устойчивый путь — один платный ключ.

## Чего конвейер не делает

- **Не публикует.** Результат — файлы в `out/` для просмотра.
- **Не ищет идеи сам.** Живой поиск тем по вовлечённости — следующий шаг;
  сейчас идею приносит агент. Кандидат на автоматизацию — `last30days-skill`.
- **Не пишет уникальную анимацию.** Это сознательный размен: восемь грамматик
  вместо рукописного кода на ролик. Уникальный «фирменный» кадр требует
  расширения грамматики слотом — см. ограничение в конце `docs/GRAMMARS.md`.
