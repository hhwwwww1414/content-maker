# Грамматики сцен: как ролик собирается без написания кода

До этого каждый ролик нёс 300–450 строк уникального TSX. Это делало конвейер
невозможным: машина не может изобретать новый визуальный язык на каждый прогон,
а человек не может писать его шесть раз за батч.

Теперь ролик — это `content/<slug>-reel.json` плюс один файл на три строки:

```tsx
import timeline from '../generated/timeline-<slug>.json';
import captions from '../generated/captions-<slug>.json';
import {createReel, type ReelTimeline} from '../reel-system/grammars/reel-engine';

export const FooReel = createReel(timeline as unknown as ReelTimeline, captions);
```

Разнообразие больше не берётся из уникального кода. Оно берётся из того, какие
грамматики ролик выбрал, в каком порядке, с какой геометрией и тональностью — а
гейт новизны по 16 осям по-прежнему заворачивает батчи, которые сходятся.

## Восемь грамматик

| Тип | Что показывает | Ключевые слоты |
|---|---|---|
| `statement` | утверждение, которое можно перечеркнуть, и вердикт | `card`, `claim`, `strikeAt`, `items`, `verdict` |
| `compare` | две-три стороны друг против друга | `rows[].glyph`, `chips` |
| `tiles` | сетка состояний: сервисы, устройства, варианты | `tiles`, `badge`, `strike`, `verdict` |
| `document` | страница со спрятанным внутри фрагментом | `visible`, `hidden`, `revealAt`, `aside` |
| `counters` | числа, которые несут весь факт | `lead`, `counters`, `chips` |
| `steps` | нумерованные правила или стадии | `steps[].note` |
| `flow` | цепочка узлов со стрелками | `nodes`, `direction`, `verdict` |
| `split` | объект, распадающийся на две части | `subject`, `splitAt`, `left`, `right` |

Типы описаны в [src/reel-system/grammars/types.ts](../src/reel-system/grammars/types.ts),
реализация — в [grammars.tsx](../src/reel-system/grammars/grammars.tsx).

## Время: слоты пишутся строками, а не миллисекундами

Грамматика никогда не упоминает время. Она говорит `"at": "l13"` — «когда
произносится реплика 13». После синтеза озвучки
[cues.mjs](../scripts/eleven/lib/cues.mjs) обходит всё дерево и дописывает
измеренное значение рядом:

| Записано автором | Появится после озвучки |
|---|---|
| `{"at": "l13"}` | `atMs` |
| `{"at": "l13", "offsetMs": 800}` | `atMs` со сдвигом |
| `{"until": "l20"}` | `untilMs` |
| `{"strikeAt": "l15"}` | `strikeAtMs` (любой ключ на `At`) |
| `{"from": "l06", "to": "l10"}` | `fromMs` / `toMs` — окна `mood` |

Нерезолвящийся id даёт `null`, а не исключение: одна битая ссылка гасит один
элемент, а не весь рендер.

## Пример главы

```json
{
  "id": "session",
  "label": "ПОЧЕМУ ЭТО ДРУГОЙ РИСК",
  "headline": "ДЛЯ САЙТА\nЭТО ТЫ",
  "fromLine": "l10",
  "toLine": "l16",
  "grammar": {
    "type": "tiles",
    "card": "ТВОЁ ОКНО · ТВОЯ СЕССИЯ",
    "badge": "ВОШЁЛ",
    "tiles": [
      {"label": "ПОЧТА",  "tone": "mint", "at": "l13"},
      {"label": "ОБЛАКО", "tone": "mint", "at": "l14"},
      {"label": "БАНК",   "tone": "mint", "at": "l14", "offsetMs": 800}
    ],
    "strike":  {"label": "РОБОТ", "at": "l15"},
    "verdict": {"label": "ЭТО ТЫ", "tone": "yellow", "at": "l16"}
  }
}
```

## Что лежит вне глав

- `chips` — накопительная лента выводов вверху, живёт весь ролик;
- `mood` — короткие цветовые заливки: `alarm`, `calm`, `split`;
- `memoryFrame` — кадр-запоминалка;
- `cta` — финальный вопрос с вариантами и тизером.

Всё это тоже адресуется по id реплик.

## Тональности

`mint` — норма, `yellow` — цена или внимание, `red` — фатально, `neutral` —
нейтрально. Значение цвета не меняется внутри ролика: к третьей главе зритель
читает смысл по цвету раньше, чем прочтёт слово.

## Что грамматики дают конвейеру

1. **Безопасные зоны по построению.** Все грамматики рисуют внутри одного слота
   `BODY` (x 90…990, y 608…~975), поэтому новый ролик не может заехать в
   оверлеи Instagram — гейт safe-zone перестаёт быть лотереей.
2. **Гейты видят текст.** Проверка фактической рамки обходит дерево грамматики
   рекурсивно, а не по списку имён слотов, — новая грамматика не может тихо
   пронести текст мимо гейта.
3. **Гейт статики работает.** `maxStaticForegroundSeconds` собирает все
   разрешённые cue из грамматик и чипов, поэтому ритм проверяется так же, как у
   старых роликов на `canvasActions`.
4. **Одна правка чинит все ролики.** Раньше исправление в подаче требовало
   правки в N рукописных файлах.

## Когда добавлять девятую грамматику

Только когда идея не выражается ни одной из восьми, а не когда хочется
разнообразия. Разнообразие — это комбинации и порядок; новый тип сцены — это
новый визуальный язык канала, и он должен окупаться в нескольких роликах.

Добавление: тип в `types.ts`, компонент в `grammars.tsx`, ветка в
`GrammarScene`. Всё остальное — движок, разрешение времени, гейты — подхватит
автоматически.

## Ограничение, о котором стоит знать

Грамматика — это шаблон. Уникальный «фирменный» кадр вроде вытащенного из письма
кода `824 519` в ней не выражается: она даст чип «КОД ИЗ ПИСЬМА», а не крупную
пломбу с цифрами. Если такой кадр критичен для обложки — либо расширяем
подходящую грамматику слотом, либо ролик получает один дописанный компонент
поверх движка. Второе — исключение, а не норма.
