# Фабрика Reels

Один запрос к Claude Code («сделай ролик про X») запускает скилл `editorial-pipeline`. Он ведёт проект от сценария до MP4 через `node studio/reel.mjs` и никогда не публикует сам.

## Команды

```bash
node studio/reel.mjs new my-reel --topic "Тема"     # studio/projects/my-reel.json
node studio/reel.mjs run my-reel                     # полный цикл, останавливается на каждом гейте
node studio/reel.mjs run my-reel --preview-only      # только 540×960
node studio/reel.mjs run my-reel --voice             # разрешает купить новый дубль
node studio/reel.mjs approve my-reel --script --facts --by "Имя"
node studio/reel.mjs status my-reel
node studio/reel.mjs scene my-reel <sceneId>         # перерендер одной сцены
node studio/reel.mjs storyboard my-reel

node studio/import-voice.mjs my-reel --from <legacy-slug>   # взять готовый дубль из public/generated, 0 квоты
node studio/visual-test.mjs my-reel [--update]              # визуальная регрессия
node --experimental-strip-types --no-warnings --test 'studio/tests/*.test.mjs'
```

Коды выхода `run`: 2 — сценарий невалиден, 3 — нужно одобрение, 4 — нужна озвучка, 5 — рендер или QA упали.

## Цикл

| Шаг | Что происходит | Где останавливается |
|---|---|---|
| Проект | JSON из `studio/projects/` или любой путь | |
| Проверка сценария | `pipeline.py validate --stage=script`: схема, источники, реплики-cue, разнообразие | код 2 |
| Согласование | статусы `factCheck` и `scriptApproval` | код 3, печатает текст |
| Озвучка | готовый дубль → кэш → покупка только с `--voice` | код 4, печатает цену |
| Тайминги | сцены и субтитры из измеренных слов | |
| Черновик | рендер 540×960 и раскадровка | код 5 |
| QA | кадры, субтитры, контраст, звук, движение | код 5 |
| Финал | 1080×1920 H.264, QA, сверка Whisper | код 5 |

## Единый стандарт

Все числа лежат в [config/reel.standards.json](../config/reel.standards.json), их читают Python, Node и Remotion: цель 30 с, окно 25–35 с, ускорение голоса не больше ×1,1, безопасная зона 80–940 × 200–1600, минимальный текст 30 px, субтитры от 44 px, контраст от 4,5.

Если старому проекту нужны другие рамки, он задаёт поле `limits`. Так `gps-offline.json` сохраняет свои 20–25 с.

## Аудио определяет тайминг

- `scene.start`, `scene.duration`, `durationSeconds` и `captions` вычисляет `applyWordTimings` из слов озвучки. Вручную они не задаются.
- Начало слова уточняется по реальной энергии звука (`studio/lib/onsets.mjs`), потому что выравнивание может ставить первое слово предложения в паузу.
- Анимация привязывается к словам: `"cue": "снял"`, `"кадр#2"` для второго вхождения или число секунд от начала сцены. Если слово не произносится в этой сцене, валидатор и рендер падают.
- Переход центрирован на первом слове новой сцены.

## Сцена

```json
{
  "id": "hook",
  "voice": "Ты включил телевизор.",
  "onScreen": "ТЕЛЕВИЗОР СНИМАЕТ ЭКРАН",
  "thought": "...", "animation": "...", "sources": ["imc"],
  "visual": {
    "backdrop": "grid",
    "camera": [{"cue": "включил", "scale": 1.03, "y": -6}],
    "transition": {"type": "iris", "origin": [0.5, 0.45]},
    "layers": [{"type": "tv", "box": [110, 500, 800, 800], "powerCue": "включил"}]
  }
}
```

Слои описаны в [src/editorial/kit/](../src/editorial/kit/), их список — в [visual-catalog.json](../studio/lib/visual-catalog.json).

| Смысл реплики | Приём | Слой |
|---|---|---|
| Сильное короткое утверждение | кинетическая типографика | `kinetic` (`rise`, `mask`, `punch`, `slide`, `track`) |
| Процесс, цепочка, кто кому передаёт | схема, которая работает | `flow` |
| Одна цифра | счётчик, приземляется на произнесённом слове | `counter`, `ring` |
| Масштаб, «сколько людей» | толпа знаков | `unitgrid` |
| Было и стало, кто прав | карточки | `compare` |
| Условия и исключения | список с отметками | `checklist` |
| Что делает устройство | устройство и его действие | `tv`, `phone` |
| Сжатие данных | мозаика становится кодом | `fingerprint` |
| Решение, запрет, закон | удар штампа, документ | `stamp`, `document` |
| Хронология | рельса с датами | `timeline` |
| Участники | именные плашки | `roster` |
| Вопрос зрителю | варианты ответа на их словах | `poll`, `callout` |
| Куда смотреть | свет | `light` (`sweep`, `spot`, `glow`) |

Темы: `signal`, `paper`, `cobalt`, `solar`. Субтитры: `plate`, `ink`, `tape`. Фоны: `aurora`, `grid`, `paper`, `rays`, `dots`. Переходы: `iris`, `whip`, `shutter`, `diagonal`, `zoomThrough`, `blinds`, `cut`.

Валидатор не пропустит повтор рецепта сцены, одинаковый главный слой подряд, одинаковый переход подряд и меньше трёх разных главных слоёв в ролике. Он не проверяет вкус: выбор приёма по смыслу остаётся за автором.

## Ручная доработка

- Поправить одну сцену: её блок `visual` в JSON, затем `reel.mjs scene`.
- Нужно то, чего нет в слоях: компонент в [src/editorial/custom/](../src/editorial/custom/index.ts) и `"component": "<имя>"` на сцене. `useScene()` даёт те же часы и cue.
- Смотреть вживую: `npx remotion studio src/editorial/index.tsx --props=runs/studio/<id>/props.json`.

## Озвучка и квота

Правки визуала никогда не тратят квоту: дубль хранится в `runs/studio/<id>/voice-cache/` по хешу текста, голоса и настроек, а `--cache-only` ничего не запрашивает. Покупка возможна только при `factCheck: reviewed` и `scriptApproval: approved`. Правка текста после одобрения снимает одобрение. Один новый дубль стоит столько символов, сколько в сценарии; ключи `ELEVENLABS_API_KEY`, `_2`, `_3`, `_4` перебираются по порядку.

Статус `scriptApproval: "demo"` позволяет собрать ролик из уже готового дубля, но запрещает покупку и оставляет `publishReady: false`.

## Что проверяется автоматически

| Проверка | Где | Когда падает |
|---|---|---|
| Текст в безопасной зоне, переполнение, размер с учётом камеры, наложение элементов | `LayoutGuard`, каждый кадр рендера | сразу, с номером кадра и текстом |
| Формат, длительность, полное декодирование, чёрные кадры, вспышки | `qa.mjs` | отчёт `-qa.json` |
| Контраст субтитров по пикселям | `qa.mjs` | ниже 4,5 |
| Застывшая сцена | `qa.mjs` | сцена стоит дольше 2 с |
| Движение на словах-cue | `qa.mjs` | меньше 85 % cue с движением |
| Речь внутри слов субтитров | `qa.mjs` | меньше 95 % |
| Громкость, клиппинг, обрезка | `qa.mjs` | вне −20…−12 LUFS |
| Голос совпадает с субтитрами на слух | `sync-check.py`, локальный Whisper | медиана больше 150 мс, p95 больше 350 мс |
| Кадры не изменились | `visual-test.mjs` | блок отличается от базовой линии |

Машина не оценивает интонацию, вкус и правдивость. Перед публикацией нужен ручной просмотр; его итог записывается в `out/studio/<id>-manual-review.json`.
